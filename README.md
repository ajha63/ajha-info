# ajha.info

Repositorio de mi página personal **[ajha.info](https://ajha.info/)**.

Este sitio funciona como mi espacio personal en Internet para compartir mi experiencia profesional, intereses y contenido relacionado con tecnología, operaciones en la nube e inteligencia artificial.

## Sobre el sitio

**ajha.info** reúne información sobre mi perfil profesional y publicaciones orientadas principalmente a temas como:

* Cloud Computing y servicios de AWS.
* Cloud Operations y soporte técnico.
* Automatización y prácticas operativas.
* Inteligencia Artificial aplicada a TI y operaciones.
* DevOps, herramientas y tecnologías emergentes.
* Experiencias, aprendizajes y opiniones sobre la evolución de la industria tecnológica.

El objetivo es mantener un espacio propio donde pueda documentar conocimientos, compartir experiencias y publicar contenido técnico de forma clara y accesible.

## Estructura

El sitio está basado originalmente en la plantilla **Miniport** de [HTML5 UP](https://html5up.net/) y ha sido adaptado para funcionar como mi página personal.

A medida que el sitio evolucione, este repositorio servirá como base para incorporar nuevas secciones, publicaciones y mejoras en diseño, contenido y experiencia de navegación.

## Tecnologías y recursos

El proyecto utiliza recursos incluidos originalmente con la plantilla Miniport, entre ellos:

* HTML5 / CSS3
* JavaScript / jQuery
* Font Awesome
* Responsive Tools
